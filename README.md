# library-loans — облік видачі книг у бібліотеці коледжу

Практична робота № 8 «Пояснення та виправлення коду з AI-асистентом».

> Модуль містить помилки, про які повідомили користувачі (див. ISSUES.md).
> До завдання 5 код у `src/` не змінюйте.

## Запуск

```
npm install
npm test
```

## Правила бібліотеки (вимоги)

1. **Номер читацького квитка**: префікс `KP` (денна форма) або `ZV` (заочна), дефіс,
   чотири цифри, скісна риска, дві цифри року вступу. Приклад: `KP-0123/26`.
2. **Строк повернення** — 14 днів від дати видачі. Дата видачі в записі про видачу
   після цього не змінюється.
3. **Штраф** — 5 грн за кожен день прострочення, але не більше 100 грн.
   Повернення в день строку або раніше — без штрафу.
4. **Ліміт**: читач може мати на руках не більше 3 книг одночасно. Новий читач,
   який ще не брав книг, може отримати книгу. Неактивному читачу видача заборонена.
5. **Продовження строку** (нова функція, див. `review/`): не більше одного разу,
   на 7 днів, лише для неповернутої книги й лише до закінчення строку.

## Структура

```
src/library.js        модуль обліку
tests/library.test.js наявні тести
ISSUES.md             звіти користувачів про помилки
review/renew.diff     зміна колеги для огляду (завдання 8)
```
